Powerful Features

Everything you need in a modern, non-blocking HTTP server

CGI Support

Execute dynamic content through Common Gateway Interface. Full support for Python and other CGI-compatible languages.

Non-Blocking I/O

Efficient event-driven architecture using poll() for handling multiple concurrent connections without blocking the main thread.

File Uploads

Handle multipart/form-data POST requests with support for large file uploads and proper content-length validation.

Virtual Hosts

Configure multiple server blocks on different ports with custom settings, error pages, and routing for each host.

Session Management

Cookie-based authentication with server-side session tracking and automatic expiration timeouts.

Automatic directory listing when enabled. Browse server directories with a clean, generated index page.
